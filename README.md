# Leaf

Website for **Leaf**, an RSS reader for iPhone, iPad and iPhone Duo (iOS 26 and later) where every story is a page you turn like a newspaper.

Live site: https://idrewn.github.io/leaf-site/

- [Home](https://idrewn.github.io/leaf-site/)
- [Privacy policy](https://idrewn.github.io/leaf-site/privacy.html)
- [Support](https://idrewn.github.io/leaf-site/support.html)

The site is plain HTML and CSS, published with GitHub Pages from the `main` branch. Report problems or ideas for the app through this repository's issues.
